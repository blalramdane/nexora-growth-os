Canonical structure for every prospect entering the NEXORA Growth OS.

## Core Identity
- lead_id
- business_name
- business_type
- city
- governorate
- branch_count
- website
- Facebook
- Instagram
- WhatsApp
- source
- discovered_at
- last_verified_at

## Qualification
- ICP_fit
- pain_signal
- digital_maturity
- buying_signal
- decision_maker_known
- urgency
- fit_score
- priority
- product_interest

## Sales

- pain_point

- owner

## Evidence
Every important qualification claim must have a source/evidence note.
Never invent missing fields.

Priority: P1 / P2 / P3
Pipeline: Lead / Qualified / Contacted / Replied / Discovery / Demo / Proposal / Negotiation / Won / Lost
